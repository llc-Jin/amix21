# rules（細かいルールの置き場）

## 何を入れるか
- いつも守ってほしい決まりごと。短く1トピック1ファイル。
- 例：「命名規則」「コミットメッセージの形」「触ってはいけないフォルダ」。
- `内容.md` の形で置く（例 `commit-message.md`）。

## 書き方
- 1文は短く。「〜する」「〜しない」で言い切る。
- 理由も1行そえると迷いが減る。

## CLAUDE.md との違い
- `CLAUDE.md` はプロジェクト全体の前提と大方針。
- `rules/` はそこから切り出した細かい個別ルール。

## ここに入れないもの
- 作業のやり方 → `skills/` へ。
- 担当者の役割 → `agents/` へ。
- 作業の順番 → `workflows/` へ。
