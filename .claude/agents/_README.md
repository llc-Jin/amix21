# agents（担当者の置き場）

## 何を入れるか
- 特定の役割を持つ「担当者」の定義ファイル。
- 1ファイル＝1担当者。`担当者名.md` の形で置く。
- 例：「テスト担当」「レビュー担当」「調査担当」。

## 書き方
- ファイル先頭のフロントマターに `name` `description` を書く。
- 本文にその担当者の仕事の範囲と進め方を書く。
- 必要なら使える道具（tools）やモデルを指定する。

## ここに入れないもの
- 作業のやり方そのもの → `skills/` へ。
- 担当者を順番に動かす流れ → `workflows/` へ。
- 全体に効かせる規約 → `rules/` へ。
