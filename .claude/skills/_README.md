# skills（手順書の置き場）

## 何を入れるか
- 決まった作業の「やり方」を書いた手順書。
- 1フォルダ＝1スキル。`スキル名/SKILL.md` の形で置く。
- 例：「PRの作り方」「テストの追加手順」「リリース前チェック」。

## 使い方
- `SKILL.md` の先頭に説明文を書くと、Claude が場面に応じて自動で読み込む。
- 手動で呼ぶときは `/スキル名` と入力する。

## ここに入れないもの
- 担当者の役割 → `agents/` へ。
- 複数の担当者を順番に動かす流れ → `workflows/` へ。
- 細かい禁止事項やコーディング規約 → `rules/` へ。
